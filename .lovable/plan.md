# Expand Mara & Wren into a complete site

## What will be added
- Expand the home page with trust marks, firm approach, core values, benefits, and a clearer consultation invitation while preserving the existing welcoming style and animations.
- Add dedicated **About Us**, **Practice Areas**, and **Resources** pages with consistent navigation and footers.
- Add individual detail pages for each practice area and each featured resource so every link leads to a complete destination.
- Include team profiles, firm milestones, service descriptions, downloadable-style resource cards, articles, case studies, FAQs, testimonials, and contact prompts using polished sample content where the brief does not provide specifics.
- Update the main navigation for desktop and mobile so visitors can move between all pages easily.

## Interaction and presentation
- Keep smooth scrolling and reveal-on-scroll motion, with reduced-motion support.
- Use the current soft pastel visual language, handwritten accents, typography, and approachable legal tone.
- Keep consultation and email forms as on-page confirmation experiences; they will not send or save submissions because no delivery or storage service was requested.
- Ensure layouts work cleanly on phones and desktop screens.

## Technical details
- Build each destination as a TanStack route, including unique page titles and social descriptions.
- Extract shared navigation, footer, calls to action, and section patterns to keep the site consistent.
- Use semantic design tokens and the existing button/control system throughout.
- Validate all navigation, key interactions, responsive layouts, and the production build.
